# Rotten and Hunger 4e

Модуль для Foundry Virtual Tabletop, добавляющий в систему **D&D 4e** отслеживание еды, воды и срока годности припасов. Персонажи вынуждены есть и пить во время длинного отдыха, а еда со временем портится и превращается в испорченный предмет.

## ✨ Возможности

- **Новый тип расходника — «Напиток»** (`drink`), наряду со стандартной «Едой» (`food`).
- **Срок годности** для еды и напитков. Указывается в днях, редактируется только ГМ.
- **Раздел «Питание и вода»** прямо в диалоге длинного отдыха — выбор еды и напитков из инвентаря персонажа.
- **Настраиваемые потребности по размерам существ.** Для каждого размера (Крошечный, Маленький, Средний, Большой, Огромный, Громадный) задаётся:
  - сколько фунтов еды нужно съесть;
  - сколько фунтов воды нужно выпить;
  - сколько дней можно прожить без еды;
  - сколько дней можно прожить без воды.
- **Счётчики голода и жажды.** Модуль ведёт учёт дней без еды и без воды, сбрасывая их в 0 при употреблении.
- **Сообщения в чате** с текстом вида:
  - «Персонаж сегодня поел и напился.»
  - «Персонаж поел и 3 дней без воды.»
  - «Персонаж 2 дня без еды и 3 дня без воды.»
  
  Если превышен порог из настроек — текст выделяется **красным**.
- **Порча припасов.** При каждом длинном отдыхе срок годности уменьшается на 1. Когда достигает 0 — предмет превращается в указанный в настройках (или удаляется).

## 📦 Установка

### Вручную

1. Скачайте архив с модулем.
2. Распакуйте его в папку `Data/modules/` вашей установки Foundry VTT. Итоговый путь должен быть `Data/modules/rotten-and-hunger-4e/`.
3. Запустите Foundry VTT, откройте ваш мир.
4. Перейдите в **Settings → Manage Modules** и активируйте **Rotten and Hunger 4e**.

### Через манифест (если опубликован)

1. В Foundry VTT откройте **Add-on Modules → Install Module**.
2. Вставьте ссылку на `module.json` в поле **Manifest URL**.
3. Нажмите **Install**.

## ⚙️ Настройка

Все настройки модуля находятся в **Settings → Configure Settings → Rotten and Hunger 4e** → кнопка **«Настроить»** рядом с пунктом **«Настройки еды и воды»**.

### Потребности по размерам

Таблица, в которой для каждого размера существа указываются:

| Столбец | Описание |
|---|---|
| **Еда (ф)** | Сколько фунтов еды нужно съесть за длинный отдых |
| **Вода (ф)** | Сколько фунтов воды нужно выпить за длинный отдых |
| **Дней без еды** | Порог: при превышении строка в чате станет красной |
| **Дней без воды** | То же для воды |

Значения по умолчанию:

| Размер | Еда (ф) | Вода (ф) | Дней без еды | Дней без воды |
|---|---|---|---|---|
| Крошечный (tiny) | 1 | 1 | 3 | 2 |
| Маленький (sm) | 1 | 1 | 3 | 2 |
| Средний (med) | 2 | 2 | 3 | 2 |
| Большой (lg) | 4 | 4 | 3 | 2 |
| Огромный (huge) | 8 | 8 | 3 | 2 |
| Громадный (garg) | 16 | 16 | 3 | 2 |

### Предметы-замены при порче

Выпадающие списки со всеми предметами типа «Расходник» из вкладки **Items**:

- **Испорченная еда** — во что превращается просроченная еда.
- **Испорченный напиток** — во что превращается просроченный напиток.

Если оставить поле пустым — просроченный предмет просто удаляется.

## 🎮 Использование

### Подготовка припасов

1. Создайте предмет типа **Расходник** (`Consumable`).
2. Укажите тип: **Еда** или **Напиток**.
3. Заполните поле **Срок годности (дней)** (доступно только ГМ).
4. Заполните стандартное поле **Вес** — от него зависит расчёт потребления.
5. Выдайте предмет персонажу.

> **Важно:** для корректной работы модуля у еды и напитков должно быть заполнено поле **Вес**.

### Длинный отдых

1. Откройте лист персонажа и нажмите кнопку длинного отдыха.
2. В появившемся окне найдите раздел **«Питание и вода»**.
3. Отметьте галочкой нужные предметы и укажите **количество единиц**, которое персонаж употребит.
   - Сумматор справа покажет общий вес по каждому блоку (еда / вода).
   - Количество ограничено только вашим запасом.
4. Подтвердите длинный отдых.

После отдыха модуль:

- спишет указанное количество единиц еды и воды;
- обновит счётчики дней без еды и без воды;
- уменьшит срок годности **всей** еды и напитков в инвентаре персонажа на 1;
- превратит просроченные припасы в указанный предмет (или удалит);
- добавит в сообщение чата строку с итогом (красную при превышении порога).

## 🧩 Совместимость

- **Система:** D&D 4e (`dnd4e`)
- **Foundry VTT:** v14 и выше
- **Проверено с:** D&D 4e 0.9.3

Модуль не конфликтует с другими расширениями листа персонажа и диалога отдыха — вся логика встраивается через публичные хуки и патч `ApplicationV2._onSubmitForm`.

## 🔧 Для разработчиков

### Кастомный хук

Модуль предоставляет хук, который срабатывает при подтверждении длинного отдыха — **до** того, как система начнёт обрабатывать отдых:

```javascript
Hooks.on('rotten-and-hunger-4e.longRestConfirmed', ({ app, actor, event }) => {
  console.log('Confirmed long rest for', actor.name);
});
```

Хук вызывается синхронно. Если вы хотите вмешаться в обработку, возвращайте Promise — но помните, что оригинальный обработчик отдыха его не ждёт.

### Флаги

На **Item** хранится:
- `flags.rotten-and-hunger-4e.expiration` — `number`, срок годности в днях.

На **Actor** хранится:
- `flags.rotten-and-hunger-4e.daysWithoutFood` — `number`, дней без еды.
- `flags.rotten-and-hunger-4e.daysWithoutWater` — `number`, дней без воды.
- `flags.rotten-and-hunger-4e.lastConsumption` — `{ ate, drank, daysWithoutFood, daysWithoutWater }`, итог последнего отдыха.
- `flags.rotten-and-hunger-4e.pendingConsumption` — временный флаг на время отдыха, снимается автоматически.


## 🐛 Известные ограничения

- Счётчики голода и жажды пока не отображаются в листе персонажа — только через флаги актора.
- Модуль не следит за едой, лежащей в контейнерах (сумках, рюкзаках) — только за предметами в инвентаре актора.

## ❓ FAQ

**Почему поле «Срок годности» не показывается?**
Убедитесь, что:
- предмет имеет тип **Расходник**;
- тип расходника — **Еда** или **Напиток**;
- модуль включен.

**Почему еда не портится после отдыха?**
Проверьте, что у еды заполнен срок годности > 0. Если поле пустое или 0 — модуль считает, что предмет не портится.
